# Research always comes before content

Every Content Piece is written from a Research Brief, never from the model's own knowledge alone. If a user asks for a blog or LinkedIn post on a Topic that has no Research Brief yet, research runs first; later pieces on the same Topic reuse that brief. We chose this so every piece can cite Sources and all pieces on a Topic say the same things, at the cost of slower and more expensive first requests. The user controls which Topic is active and can force fresh research at any time.
